# PlaceContext brand assets

The PlaceContext mark combines a long-beaked kiwi bird with three connected nodes: a small,
grounded identity for durable jobs and connected context. The product name remains **PlaceContext**.

| Asset | Use |
| --- | --- |
| [Light wordmark](placecontext-logo-light.svg) | Light backgrounds and the README fallback. |
| [Dark wordmark](placecontext-logo-dark.svg) | Dark backgrounds. |
| [Kiwi mark](placecontext-mark.svg) | Square placements and icon exploration. |

The SVGs are self-contained: no scripts, remote images, or downloadable fonts. The wordmarks use a
system sans-serif font stack. Each asset has an accessible title and description. Use descriptive
alternative text when embedding the files.

## Palette and placement

Fern green `#143A2D`, pale lime `#D2EAA1`, leaf green `#55762D`, and warm white `#F2F7EC`.
Keep the aspect ratio intact and clear space of at least one-quarter of the square mark's width.
Use the complete wordmark at 360 px wide or larger; use the square mark for smaller placements.
A dedicated simplified favicon should be checked at 16 px and 32 px before replacing the portal icon.

The README selects the appropriate wordmark with a `<picture>` element and falls back to the light
version. This change does **not** replace the running portal's favicon, tenant branding, or application
assets. Those should be updated separately with UI regression checks.
