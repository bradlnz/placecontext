# Charts and analytics

*Turn job results and project data into readable views.*

## Job output

Choose the job's return type to control its primary artifact:

| Return type | Result |
|---|---|
| **JSON** | Stored as JSON and displayed in a readable form |
| **Table** | Rendered as an HTML table report |
| **Chart** | Rendered as a chart artifact |
| **HTML** | Stored as an openable HTML document |
| **CSV** | Stored as a downloadable CSV |
| **Text** | Stored as plain text |
| **PDF / Image / Video** | Stores the matching file written by the job |

JSON results containing a small numeric series can also be charted directly in the run detail.
Keep standard output clean and send diagnostic messages to standard error.

## SQL analytics

Open **Data → Analytics** to create charts from project tables. A chart uses a read-only `SELECT`:

```sql
SELECT status, count(*)
FROM jobs
GROUP BY status
ORDER BY status;
```

The first column supplies labels and numeric columns supply the series. Charts can be displayed
as bar, line, or pie charts and also appear on the Dashboard.

Charts load their renderer on demand. Keep queries small and aggregate the data before charting it;
the page can display the chart as soon as its data and renderer are ready.

## Data profiles

Open **Data profiles** for an immediate view of the project's saved chart snapshots. The
unsaved project overview selects up to 12 charts; **Choose data** lets you change the selection.
You can inspect sources before creating a saved dashboard. **Save view** keeps your layout,
question and optional watch targets private to your account in this project.

- **Overview** displays a grid of saved charts, with profiles that need attention first, then older snapshots.
- **Decisions** shows measured signals, proposed next steps and Jev's support for each review decision.
- **Needs attention** narrows the chart grid to unusable, stale or structurally ambiguous evidence.
- **Explore values** opens one selected chart and its values table, with a source selector in saved chart order.

The summary cards show measured signals and values, attention checks, review decisions and
combined snapshot confidence. Search filters visible panels without changing the saved source selection.
Select a chart title or decision to inspect its source reference, measured values, proposed next
step and evidence checks in the details panel. Expand a check for the reason and next
investigation. **Explore values** opens the exact displayed values; chart categories are not
source row counts. Refresh reloads saved snapshots and does not rerun source queries.

### Measured signals and micro decisions

Each selected chart supplies one signal from its first named measure, or the measure selected
by its watch target. The dashboard calculates the displayed minimum, maximum, mean, median,
spread and value count before making any model request. It does not infer units, chronological
order, source population statistics or business limits from labels. These are measurements of
the saved chart's values; source coverage remains separate.

Choose **Evaluate with Jev** to assess the signals in this view, or **Evaluate** beside one
signal. The service rereads authorized charts and verifies the snapshot and target fingerprint
before sending each signal's chart, measurements and explicit review question to Jev. A view
contains at most 12 signals; at most two requests run at once. **Cancel review** cancels the
batch without applying incomplete results. Opening, searching and switching views do not call
the model. Model usage requires the configured project Jev service and may incur provider usage.

Jev returns a support probability. The dashboard combines that judgment with the measured
evidence to make a bounded decision about reviewing the data:

| Decision | Meaning and next step |
|---|---|
| **Review** | Jev support is at least 90%; inspect the displayed values and source |
| **Watch** | Support is at most 10%; recheck when evidence or the target changes; this does not certify business health |
| **Hold** | Support is between those boundaries, or disagrees with the measured target comparison; a person should review the evidence |
| **Needs data** | The evidence is stale, unusable, ambiguous or incompatible with its target; refresh or repair it before Jev evaluation |
| **Unavailable** | Jev failed or returned an unusable judgment; retry without treating it as an assessment |

The evidence disclosure shows the exact question, measured basis, model when available,
assessment time and evidence fingerprint. The measurements, proposal and explanation of the
decision rule are local calculations; they are not presented as prose generated by Jev.
The support probability never raises the independent data-confidence band.

Decisions are local to the open view. Refreshing snapshots or changing the selected sources
or targets clears them; searching and switching display modes preserve matching decisions.
The queue proposes review work. It does not change phone routing, place calls or execute
external actions.

### Optional watch targets

Open **Add target** in a signal's details, choose its measure and statistic, then specify an
**At most** or **At least** value in the chart's own units. **Apply target** updates the open
view immediately. **Save view** persists it with the encrypted private dashboard. Existing
saved dashboards remain compatible and begin without targets.

One target can be set per chart, using Minimum, Maximum, Mean or Median. Equality meets the
target. Computed means and medians allow a few floating-point steps solely for numerical
roundoff at the equality boundary; the evidence records that allowance. Minimum and Maximum
comparisons remain strict. A model judgment cannot conceal a measured target breach: a
contradiction becomes **Hold**. Missing or renamed measures require updating the target.

### Confidence and freshness

| Band | Meaning in the current implementation |
|---|---|
| **Unknown** | No usable displayed values, or a selected source chart is missing |
| **Low** | Usable values exist, but the snapshot is stale, has an unknown or invalid timestamp, or has ambiguous labels or invalid structure |
| **Medium** | Displayed values are usable and no attention check failed; source coverage remains unverified |
| **High** | Reserved for verified evidence; the current snapshot contract cannot earn this band |

A snapshot is **Current** for 24 hours after generation, **Aging** for up to 7 days, then
**Stale**. These are default review windows, not a promise about the underlying records or a
business SLA. The assessment time is shown in the profile. Reload snapshots to reassess.

Saved charts do not retain the full source dataset, query provenance, source null rates or
verified sampling coverage. Chart generation can also omit categories or normalize values.
The checks describe the stored snapshot and cannot certify that source data is complete or
correct. Open Analytics to inspect the source and regenerate it when needed. Reloading a
dashboard does not rerun the source query.

### Investigate with Jev

Suggested questions are grounded in the selected profile's displayed categories and measures.
Choosing a suggestion fills the question box; it does not make a model request. Edit the
yes/no question and select **Ask Jev** when ready. Jev receives the chart snapshots selected for the view,
not unseen source rows. Its probability estimates the answer to your question and remains
separate from the evidence confidence band.

Changing the question, profile focus, view or chart data clears the prior displayed assessment.
Missing source charts block analysis until the view is repaired. A changed snapshot fingerprint
requires reloading before another analysis. Model analysis requires the project's configured
Jev service and may incur provider usage; exploring profiles does not.
