Placecontext is a self-hosted platform for operational data, automation, CRM, artifacts, and optional OpenSearch analytics. It also turns connected Macs and on-prem computers into a private fleet for 3D rendering, media processing, and sharded local AI.

One durable workspace

The platform around your compute.

Keep rendering, local AI, data pipelines, business data, optional search, and customer operations connected instead of scattered across disconnected tools.

01

Data section

Create tables, import CSV files, write SQL views, map job outputs into queryable data, and model entities with records, graphs, and analytics.

02

Artifacts view

Search and filter outputs across projects, inspect versions, preview JSON, CSV, PDF, image, video, and HTML files, and share expiring links.

03

Job code editor

Supported runtimes: Node.js, Python, Go, Ruby, and C#. Write multi-file jobs, test and deploy them, then chain them into a data pipeline or any automation.

04

Optional OpenSearch

Connect OpenSearch only when you need it: search indexes through the authenticated server proxy, explore fields, turn aggregations into charts, and save reusable dashboards.

05

CRM and automation

Move customers from lead to retention with calendars, appointments, notes, messages, and automations that file outputs against their records.

06

Agents and MCP

Give automation and AI clients governed access to the same data and operations as your team.

07

Local AI shards

Split supported local models across multiple computers for private inference without sending prompts outside your network.

Your infrastructure

Heavy compute without the cloud bill.

Deploy the control plane on a local machine, private server, or cloud VM. Join Macs and on-prem Linux machines over Tailscale, then let worker nodes run renders, media jobs, automations, and sharded local models while source data and secrets stay in your environment.
